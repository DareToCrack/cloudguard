# Sample Data

This directory contains real output from CloudGuard, generated by running
the CLI against the bundled demo dataset:

```bash
python cli/cloudguard_cli.py scan --output sample_data/example_scan_report.json --format json
python cli/cloudguard_cli.py scan --output sample_data/example_scan_report.html --format html
```

- **`example_scan_report.json`** — full structured scan output: every
  finding with its severity, evidence, remediation guidance, and
  compliance mapping, plus the computed risk score.
- **`example_scan_report.html`** — the same scan rendered as a
  self-contained, print-to-PDF-friendly report (open it directly in a
  browser).

These are provided so you can see CloudGuard's real output without
running the tool first. The synthetic account they describe (bucket
names, IAM users, security groups, etc.) is defined in
`backend/app/scanners/demo_data.py` and is intentionally designed to
trigger a realistic, varied mix of severities across every scanner.
